开始

最近写作的欲望特别强烈，于是便有了做博客网站的想法。在google了一番后，以及对自己的了解，发现了两个有意思的博客，gitblog和Gmeek，其中Gmeek受到了gitblog的启发。这两个博客的构建都是基于github actions功能，正好我一直对github actions比较感兴趣，正好借着这个机会学习一下。

思路

我的想法是，先学习github actions，然后学习这两个博客的生成原理，最后根据学习到的原理尝试制作自己的博客主题。

那么接下来，就开始第一步的尝试吧。

任务

  • [x] 编写一个workflow脚本，将issue链接更新到README文件

任务分解

任务触发条件 yaml on: workflow_dispatch: issues: types: [opened, edited] issue_comment: types: [created, edited] push: branches: - master paths: - main.py 这是gitblog仓库中生成README文件的触发条件，根据文档Events that trigger workflows，可以得出workflow触发的条件 1. workflow_dispatch表示允许手动触发 2. 当issue发生变化时，表示有新文章发布 3. 当issue评论发生变化时，表示有新评论发布 4. 当主分支收到push时，表示项目文件有变化 5. 当push改变了main.py时，表示项目核心文件有变化

任务逻辑 ```yaml jobs: sync: name: Generate README runs-on: ubuntu-latest if: github.repository_owner_id == github.event.issue.user.id || github.event_name == 'push' steps: - name: Checkout uses: actions/checkout@v4 - name: Set up Python uses: actions/setup-python@v5 with: python-version: 3.13 cache: pip cache-dependency-path: "requirements.txt"

  - name: Install dependencies
    run: |
      pip install -r requirements.txt

  - name: Generate new md
    run: |
      python main.py ${{ secrets.G_T }} ${{ github.repository }} --issue_number '${{ github.event.issue.number }}'

  - name: Push README
    run: |
      git config --local user.email "action@github.com"
      git config --local user.name "GitHub Action"
      git add BACKUP/*.md
      git commit -a -m 'update new blog' || echo "nothing to commit"
      git push || echo "nothing to push"

``` 逐行分析，job的任务就是

  1. 拉取仓库文件
  2. 配置环境
  3. 运行main.py
  4. 提交修改到仓库

任务目标

编写一个workflow，可以把现在正在写的这个issue的链接增加到README文件，并且生成index.html，使得github page可以正常访问

基于以上目标，修改得到的workflow文件 ```yaml name: Generate GitBlog README

on: workflow_dispatch: issues: types: [opened, edited] issue_comment: types: [created, edited] push: branches: - main paths: - main.py

jobs: sync: name: Generate README runs-on: ubuntu-latest if: github.repository_owner_id == github.event.issue.user.id || github.event_name == 'push' steps: - name: Checkout uses: actions/checkout@v4 - name: Set up Python uses: actions/setup-python@v5 with: python-version: 3.13 cache: pip cache-dependency-path: "requirements.txt"

  - name: Install dependencies
    run: |
      pip install -r requirements.txt

  - name: Generate new md
    run: |
      python main.py ${{ secrets.GITHUB_TOKEN }} ${{ github.repository }} --issue_number '${{ github.event.issue.number }}'

  - name: Push README
    run: |
      git config --local user.email "action@github.com"
      git config --local user.name "GitHub Action"
      git commit -a -m 'update new blog' || echo "nothing to commit"
      git push || echo "nothing to push"

`` 除此以外，精简了main.py以及requirements.txt`文件，仅保留本次任务目标所需部分。

总结

对于这种建立博客的方式，我总结了以下几个优势 1. issue自带了markdown编辑器，且可以预览 2. github page功能可以让github作为博客服务器，节省购买云服务的开销 3. issue自带评论，可以方便的在博客中支持评论功能
